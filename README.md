# flet-syncfusion-slider
FletSyncfusionSlider control for Flet

## Installation

Add dependency to `pyproject.toml` of your Flet app:

* **Git dependency**

Link to git repository:

```
dependencies = [
  "flet-syncfusion-slider @ git+https://github.com/ositoMalvado/flet_syncfusion_slider",
  "flet>=0.27.6",
]
```

* **PyPi dependency**  

If the package is published on pypi.org:

```
dependencies = [
  "flet-syncfusion-slider",
  "flet>=0.27.6",
]
```

Build your app:
```
flet build macos -v
```
